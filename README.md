# Grid-Based Pattern Generator

A programmatic visual generation tool built with Python to explore algorithmic grid structures and geometric composition.

## Project Overview
This tool generates structured visual matrices, applying mathematical rules and random seed variations to build complex patterns. It serves as an experimental bridge between computational logic and generative visual design.

## Tech Stack
* **Language:** Python 3.10+
* **Libraries:** NumPy, Matplotlib
